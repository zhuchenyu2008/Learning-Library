# Learning-Library 必背记录规范

## 一、基本原则

必背内容按照**课次**保存。

每节课最多建立一个“必背” Markdown 文件，例如：

```text
政治1_必背_必修一第1-2课_2026-09-08_周二.md
政治2_必背_必修一第3课_2026-09-10_周四.md
```

课后发现属于这节课的新必背内容，继续追加到该课文件中，不另建新文件。

## 二、记录内容

只记录真正需要记忆的内容，包括：

- 老师明确要求背、记住的内容
- 老师明确强调考试需要掌握的固定表述
- 定义、原理、公式、固定搭配等需要直接记忆的内容
- 错题中暴露出没有记牢、需要补充记忆的知识
- 课后整理中确认必须记住的核心内容

不把整份课堂笔记、长篇解释、例子、完整错题解析复制进必背文件。

## 三、记录格式

统一只使用编号列表：

```markdown
1、生产力决定生产关系，生产关系反作用于生产力。
2、生产关系包括生产资料所有制关系、生产中人与人的关系、产品分配关系。
3、生产力与生产关系的矛盾、经济基础与上层建筑的矛盾，是贯穿人类社会始终的基本矛盾。
4、……
```

不使用：

- 多级标题
- “必背：”
- “易错：”
- “老师强调：”
- 大量空行
- 复杂表格

原则：

> 打开文件就直接开始背。

## 四、内容要求

每一条应：

1. 表述完整
2. 尽量简洁
3. 保持知识准确
4. 不为了缩短而改变原意
5. 能直接用于记忆和复习

如果一个知识点需要多句话才能完整表达，可以写在同一个编号内，不必拆成很多小标题。

## 五、不得虚构

只有确实有依据的内容才能写入。

不得：

- 猜老师是不是要求背
- 猜教材原话
- 猜看不清或听不清的内容
- 自己编造考试重点

无法确认时，不写入正式必背列表。

## 六、重复内容

同一节课中相同或高度重复的必背内容只保留一次。

如果后续出现补充，应优先完善原有条目，不重复写一遍。

例如原来：

```markdown
1、生产力决定生产关系，生产关系反作用于生产力。
```

后来有新的必要补充，可以直接改成：

```markdown
1、生产力决定生产关系，生产关系反作用于生产力；生产关系适应生产力时促进其发展，不适应时阻碍其发展。
```

## 七、新增内容

已有：

```markdown
1、……
2、……
3、……
```

后来新增必背内容，继续：

```markdown
4、……
5、……
```

不另建第二个同课次必背文件。

## 八、课次不明确时

如果不知道属于第几次课：

1. 查看仓库已有课堂资料
2. 根据相关内容和日期判断
3. 必要时查询 Google 日历
4. 按该科目实际上课顺序推算
5. 考虑取消课、补课、调课

时间统一按照**北京时间**处理。

仍无法可靠确认时，再向用户确认。

## 九、核心规则

```text
1. 必背按照课次走。

2. 一节课最多一个“必背”Markdown文件。

3. 文件名遵守：
   科目+课次_必背_课程内容_YYYY-MM-DD_周X.md

4. 文件内容只使用：
   1、xxxxxx
   2、xxxxxx
   3、xxxxxx

5. 不使用多级标题、复杂字段、大量空行。

6. 只记录真正需要背的内容。

7. 同一内容不重复记录，新补充优先完善原条目。

8. 不确定的信息不得猜测。

9. 不知道课次时可以结合仓库记录和 Google 日历推算。
```

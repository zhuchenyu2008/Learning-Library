# Learning-Library 错题存储规范

## 一、基本原则

错题跟随每一次课堂保存，不建立独立总错题库。

每节课最多只建立一个错题 Markdown 文件：

```text
科目+课次_错题_课程内容_YYYY-MM-DD_周X.md
```

例如：

```text
政治1_错题_必修一第1-2课_2026-09-08_周二.md
```

无论这节课有 1 道还是 20 道错题，都写进同一个文件。

课后作业产生的错题仍归属于布置该作业的课堂。

---

# 二、存放位置

例如：

```text
政治/
└── 2026-首考/
    └── 课堂/
        └── 政治1_必修一第1-2课_2026-09-08_周二/
            ├── 政治1_课堂笔记_必修一第1-2课_2026-09-08_周二.md
            ├── 政治1_要背的东西_必修一第1-2课_2026-09-08_周二.md
            ├── 政治1_课后整理_必修一第1-2课_2026-09-08_周二.md
            └── 政治1_错题_必修一第1-2课_2026-09-08_周二.md
```

---

# 三、每道错题必须包含的内容

每一道错题固定包含：

```text
原题
我的错误答案
正确答案
解析
```

缺少信息时不得猜测。

不知道用户当时的答案：

```text
未记录
```

无法可靠确定正确答案或题目内容：

```text
无法确认
```

---

# 四、错题文件格式

错题文件使用紧凑格式，不使用大量空行和过多标题层级。

推荐固定格式：

```markdown
# 政治1 错题｜必修一第1-2课

## 01
**原题：** 下列关于生产力和生产关系的说法正确的是？  
A. 生产关系决定生产力  
B. 生产力决定生产关系  
C. 生产力属于上层建筑  
D. 二者不存在相互作用  
**我的错误答案：** A  
**正确答案：** B  
**解析：** 本题考查生产力与生产关系的关系。生产力决定生产关系，生产关系反作用于生产力。A把“决定作用”和“反作用”颠倒了，因此错误。课堂笔记中老师强调过，判断这类题时要特别注意“谁决定谁”。

## 02
**原题：** ……  
**我的错误答案：** C  
**正确答案：** A  
**解析：** ……
```

要求：

- 一题只使用一个 `##`
- `原题 / 我的错误答案 / 正确答案 / 解析` 使用加粗字段，不单独使用三级标题
- 不在每一个字段之间塞大量空行
- 保持紧凑但仍然清晰
- 不为了排版好看制造大量无意义留白

---

# 五、原题要求

原题应尽可能完整，包括：

- 题干
- 必要材料
- 所有选项
- 必要条件
- 对解题有用的数据

选择题必须保留所有选项。

例如：

```markdown
**原题：** 某材料体现了生产关系中的哪一方面？  
A. 劳动者  
B. 生产资料所有制  
C. 劳动工具  
D. 劳动对象
```

不能只写：

```text
这题选什么？
```

如果题目中的图片、图表等无法完整文字化，应把能够可靠提取的信息写出来，无法确认的部分明确注明，不得猜测。

---

# 六、我的错误答案

记录用户实际做错时的答案。

例如：

```markdown
**我的错误答案：** C
```

主观题：

```markdown
**我的错误答案：** 生产关系决定生产力。
```

如果没有记录：

```markdown
**我的错误答案：** 未记录
```

不得根据正确答案反推用户可能选了什么。

---

# 七、正确答案

必须明确。

选择题：

```markdown
**正确答案：** B
```

必要时：

```markdown
**正确答案：** B．生产力决定生产关系
```

主观题则写出适合以后复习的正确答案。

---

# 八、解析要求

解析是错题文件最重要的部分之一。

解析不能只写：

```text
A错，B对。
```

至少应解决：

1. 这道题考什么
2. 正确答案为什么正确
3. 用户的错误答案为什么错误
4. 用户容易混淆在哪里
5. 应该如何判断这类题

解析应尽量简洁，不写无关内容。

---

# 九、解析必须联系仓库中的已有资料

写解析时不能把错题当成孤立题目处理。

必须优先查阅和联系该课程目录中的相关文件，例如：

```text
课堂录音转文字稿
课堂笔记
要背的东西
课后整理
老师资料转写
```

还可以根据需要联系：

- 前面课程讲过的相关知识
- 后续课程对该知识点的补充
- 同知识点已有错题
- 仓库中的相关专题整理

例如：

如果错题考查：

```text
生产力与生产关系
```

而对应课堂笔记中已经记录：

```text
生产力决定生产关系，生产关系反作用于生产力。
```

解析应结合这一课堂内容解释用户为什么选错。

如果老师课堂明确说过：

```text
这里考试容易把“决定作用”和“反作用”调换
```

则应把这个课堂强调点融入解析。

原则：

> **错题解析应尽量建立在用户自己的课堂知识体系上，而不是生成一份与仓库其他资料没有关系的通用答案。**

---

# 十、引用仓库内容时的原则

使用仓库其他资料辅助解析时：

- 不机械复制整段课堂笔记
- 只提取与当前错题直接有关的信息
- 保持解析紧凑
- 如果课堂内容与通用知识表达不同，应优先忠实还原老师实际讲解，再检查其准确性
- 不得虚构“老师说过”或“课堂强调过”的内容

只有仓库资料中确实存在相关内容时，才能写：

```text
老师课堂强调……
课堂笔记中提到……
本节课整理中指出……
```

---

# 十一、解析准确性

写解析时应综合判断：

1. 原题
2. 正确答案
3. 用户错误答案
4. 当前课堂笔记
5. 当前课堂录音转文字稿
6. 要背的东西
7. 课后整理
8. 相关前后课程资料

如果发现仓库中不同文件存在冲突：

> 不应直接挑一个使用。

应先判断哪个内容更可靠；仍无法判断时明确指出冲突，不得强行编造结论。

---

# 十二、新增错题

已经存在：

```text
## 01
## 02
## 03
```

后来又发现新的错题，直接追加：

```text
## 04
```

不得：

- 新建第二个同课堂错题文件
- 把原错题重新编号
- 删除已有错题再重排

---

# 十三、相同题再次做错

如果完全相同的一道题再次做错，可以在原题下面紧凑追加：

```markdown
**再次做错：** 2026-09-15（周二，北京时间），错误答案 A。
```

如果第二次错误原因与第一次明显不同，可在解析末尾补充说明。

---

# 十四、不同题不得合并

即使两题：

- 知识点相同
- 题型相同
- 错误原因相同

只要题目不同，就应分别记录：

```text
## 03
## 04
```

错题编号代表具体题目，而不是知识点。

---

# 十五、课后作业错题

某节课布置的课后作业产生的错题，仍归入该课堂。

例如：

```text
政治1
```

9月8日上课，9月9日完成作业。

错题仍写入：

```text
政治1_错题_必修一第1-2课_2026-09-08_周二.md
```

文件日期使用课堂日期，而不是做作业日期。

---

# 十六、不知道对应课堂时

不得猜测。

依次：

1. 看题目内容
2. 看同批资料
3. 看仓库现有课堂文件
4. 看相关知识点在哪节课出现
5. 必要时查询 Google 日历
6. 按实际上课顺序推算课次
7. 考虑取消课、补课、调课

仍无法确定时再向用户确认。

时间统一按照**北京时间**处理。

---

# 十七、最终标准

一份合格的错题文件应做到：

```text
1. 一次课只有一个错题 Markdown 文件。
2. 所有错题都集中写在该文件中。
3. 每道题使用 01、02、03 连续编号。
4. 每道题必须有：
   原题
   我的错误答案
   正确答案
   解析
5. 格式紧凑，不大量使用空行和多级标题。
6. 选择题必须保留完整选项。
7. 用户错误答案必须真实，不知道就写“未记录”。
8. 解析必须说明正确答案为什么对、用户答案为什么错。
9. 解析必须主动联系仓库中的课堂笔记、录音转写、要背内容、课后整理等相关文件。
10. 只有仓库中确实有依据时，才能写“老师强调过”等内容。
11. 前后课程有相关知识时，可以联系起来分析。
12. 仓库资料之间出现冲突时不得强行猜测。
13. 新错题直接追加到原文件。
14. 完全相同的题再次做错，可以追加再次做错记录。
15. 不同题即使考点相同也不得合并。
```

# 高中英语精讲课堂笔记

## 一、阅读理解实战：菌丝忆阻器（Memristor）

本篇阅读主要围绕科学家利用菌菇菌丝发明忆阻器展开。

### 1. 核心文章梳理
- **核心发现**：科学家利用真菌网络成功制造出了类似于人类脑细胞的忆阻器设备。
- **技术优势**：因为工作原理类似于人类神经元，该设备在不使用时需要的能量极少（need less power / lower power）。
- **工作原理**：真菌网络与人体神经系统高度相似，均能通过电信号和化学信号传递信息。
- **实验结果**：随着电压增加，蘑菇的性能会下降（decrease）；但当大量菌丝聚集在一起协同工作时，它们能够进行自我修复（fix）并保持稳定，抵御电压的抑制作用。
- **未来展望**：虽然真正的“菌丝电脑”短期内不会面世，但这一突破性发现为未来的科学研究提供了广阔的前景（promising）。

### 2. 阅读解题技巧
- **首尾段寻旨法**：解答主旨题时，优先精读文章首段与尾段，寻找核心论点与最终结论。
- **跳读找结果**：遇到涉及科学实验的文章，跳过繁琐的研究过程，直接定位“研究发现/结果”寻找考点。
- **长难句抓主干**：做阅读理解时，首要任务是剥离从句（如定语从句、状语从句），找出句子的核心主谓宾成分。
- **同义替换定位**：例如 `not working` 对应 `isn't being used`，`less power` 对应 `don't need a lot of power`。
- **细节题辨析**：文中说的是“传递信息”，不能偷换成“存储信息”。

## 二、核心语法篇：句子成分与动词分类

### 1. 主语（Subject）
主语是一句话的执行者或核心讨论对象。

- **可充当主语的成分**：名词（n.）、代词、动名词（doing）、不定式（to do）、以及句子（主语从句）。
- **不可充当主语的成分**：介词短语通常只能作状语，不能作主语。
- **形式主语 `it`**：当真正的主语（如不定式短语或主语从句）过长时，为避免“头重脚轻”，会将其后置，并在句首使用 `it` 作为形式主语占位。

例：`It takes me an hour to go to the school.`
真正的主语是 `to go to the school`。

### 2. 谓语（Predicate）与非谓语（Non-predicate）
谓语代表动作或状态，并具有完整的时态结构。

**谓语的三大类别：**
1. **be 动词**：如 `am, is, are, was, were`。
2. **情态动词 + do**：如 `can, could, will, would, may, might, shall, should, must, need + 动词原形`。
3. **实义动词（拥有完整时态结构）**：如现在进行时 `is doing`、现在完成时 `have done`、一般过去时等。

**非谓语“三剑客”：**
- `doing`
- `done`
- `to do`

当句子中已经满足谓语动词数量时，多余动词必须变为非谓语形式。

### 3. 谓语数量判断
课堂核心公式：

**谓语动词的数量 = 连词的数量 + 1**

用于分析长难句和语法填空。若没有新增连词，而句中已经有足够的谓语，则待填动词通常需要考虑非谓语形式。

### 4. 及物动词、不及物动词与系动词

#### 及物动词（vt.）
自身含义不完整，需要直接接宾语。

#### 不及物动词（vi.）
自身含义完整，不能直接接宾语；若需要接名词，通常需要通过介词连接。

#### 系动词
连接主语和表语，表示状态或变化。课堂强调“系表不分离”。

系动词记忆：**五个感官、保持、变化、be、证明**。

- 五个感官：`look, sound, smell, taste, feel`
- 保持：`keep, remain`
- 变化：`become, get, turn, go, grow`
- be：`am, is, are` 等
- 证明：`prove`

若系动词后紧跟从句，可据此帮助判断表语从句。

## 三、五大基本句型

1. **主语 + 谓语**（S + V）
2. **主语 + 谓语 + 宾语**（S + V + O）
3. **主语 + 系动词 + 表语**（S + V + P）
4. **主语 + 谓语 + 间接宾语 + 直接宾语**（S + V + IO + DO）
5. **主语 + 谓语 + 宾语 + 宾语补足语**（S + V + O + C）

## 四、高频核心词汇：及物与不及物动词

### 1. 常见纯不及物动词（仅 vi.）

| 单词 | 中文含义 | 必搭配介词 / 例句 |
| --- | --- | --- |
| listen | 听；听从 | `listen to + 宾语`，如 `listen to music` |
| come | 来；到达 | `come to school` |
| appear | 出现 | `appear in public` |
| happen | 发生 | `sth. happen to sb.` |
| occur | 发生；出现 | `occur to sb.` |
| rise | 上升；上涨 | `The sun rises.` |
| arrive | 到达 | `arrive at + 小地点 / arrive in + 大地点` |
| belong | 属于 | `belong to + 人`；无被动、无进行时 |
| exist | 存在；生存 | `Dinosaurs existed long ago.` |
| lie | 躺；位于；撒谎 | `lie on the bed` |

### 2. 兼作及物与不及物的动词（vi. / vt. 两用）

| 单词 | vi. 不及物用法 | vt. 及物用法 |
| --- | --- | --- |
| beat | 心脏、脉搏跳动：`My heart beats fast.` | 敲、揍、打败：`Beat the drum.` |
| grow | 生长：`Plants grow well.` | 种植：`grow rice` |
| play | 玩耍：`Kids play outside.` | 演奏、打球：`play the piano` |
| smell | 散发气味：`The flower smells sweet.` | 嗅、闻：`smell the food` |
| speak | 讲话、开口：`Please speak slowly.` | 说某种语言：`speak English` |
| operate | 动手术：`operate on patients` | 操作机器、经营：`operate the machine` |
| hurry | 匆忙前行：`Hurry up!` | 催促、快速处理：`hurry him to school` |
| stand | 站立、直立：`Stand still!` | 忍受：`I can't stand noise.` |

## 五、介词与非谓语

课堂强调 `despite` 是**介词**，不是连词。

介词后若接动词，使用 `doing` 形式。

课堂补充的常见介词包括：
`for, with, without, along, by, during, against, towards, among, between, including, despite`。

## 六、课堂固定搭配

- `be able to do`：能够做某事
- `spend time doing something`：花时间做某事
- `want to do something`：想要做某事
- `belong to`：属于
- `operate on patients`：给病人做手术

## 七、课堂长难句示例

课堂分析句：

`Being able to develop microchips that act like real brain cells means you don't need a lot of power when the machine isn't being used.`

分析：
- 主句主语：`Being able to develop microchips that act like real brain cells`
- 主句谓语：`means`
- `that act like real brain cells`：课堂按定语从句分析
- `when the machine isn't being used`：时间状语从句
- 抓主干后可理解为：`Being able to develop microchips means you don't need a lot of power.`

## 八、课堂重点与易错点

1. 主语可由名词、代词、doing、to do、句子充当。
2. 介词短语通常不能充当主语。
3. `it` 可作形式主语，真正主语后置。
4. 谓语必须具有完整的时态结构；非谓语常见形式为 `doing / done / to do`。
5. 分析长难句时优先找主干，再处理从句。
6. `despite` 是介词；介词后接动词时用 `doing`。
7. 及物动词可直接接宾语；不及物动词若接宾语通常需要介词。
8. 系动词用于连接主语和表语，课堂强调“系表不分离”。
9. 阅读细节题注意原文同义替换，不要把“传递信息”偷换成“存储信息”。
10. 科学实验类阅读可优先定位研究结果、结论与变化趋势。

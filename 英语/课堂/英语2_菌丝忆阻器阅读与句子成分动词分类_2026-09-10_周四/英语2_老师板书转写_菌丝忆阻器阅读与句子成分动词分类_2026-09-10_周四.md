# 英语2 老师板书转写

## 一、五大基本句型

1. 主语 + 谓语
2. 主语 + 谓语 + 宾语
3. 主语 + 系动词 + 表语
4. 主语 + 谓语 + 间接宾语 + 直接宾语
5. 主语 + 谓语 + 宾语 + 宾语补足语

## 二、主语与谓语

### 主语
课堂板书可识别内容：
- 名词（n.）
- 代词
- doing
- to do
- 句子

课堂同时强调：介词短语通常不能充当主语。

### 谓语
课堂板书可识别内容：
- be 动词
- 情态动词 + do
- 拥有完整时态结构的实义动词

### 非谓语
- doing
- done
- to do

课堂反复强调：

**谓语动词数量 = 连词数量 + 1**

## 三、常见纯不及物动词（仅 vi.）

| 单词 | 中文含义 | 搭配 / 例句 |
| --- | --- | --- |
| listen | 听；听从 | `listen to + 宾语` |
| come | 来；到达 | `come to school` |
| appear | 出现 | `appear in public` |
| happen | 发生 | `sth. happen to sb.` |
| occur | 发生；出现 | `occur to sb.` |
| rise | 上升；上涨 | `The sun rises.` |
| arrive | 到达 | `arrive at + 小地点 / arrive in + 大地点` |
| belong | 属于 | `belong to + 人`；无被动、无进行时 |
| exist | 存在；生存 | `Dinosaurs existed long ago.` |
| lie | 躺；位于；撒谎 | `lie on the bed` |

## 四、兼作及物和不及物的动词（vi./vt. 两用）

| 单词 | vi. 用法 | vt. 用法 |
| --- | --- | --- |
| beat | 心脏、脉搏跳动 | 敲、揍、打败 |
| grow | 生长 | 种植 |
| play | 玩耍 | 演奏、打球 |
| smell | 散发气味 | 嗅、闻 |
| speak | 讲话、开口说话 | 说某种语言 |
| operate | 动手术 | 操作、经营 |
| hurry | 匆忙前行 | 催促、快速处理 |
| stand | 站立、直立 | 忍受 |

## 五、系动词

课堂板书记忆框架：**五个感官 + 保持 + 变化 + be + 证明**。

- 五个感官：`look, sound, smell, taste, feel`
- 保持：`keep, remain`
- 变化：`become, get, turn, go, grow`
- be：`am, is, are` 等
- 证明：`prove`

课堂强调：**系表不分离**。

## 六、介词

板书及课堂讲解中可确认：

`despite, for, with, without, along, by, during, against, towards, among, between, including`

课堂强调：`despite` 是介词；介词后接动词时用 `doing`。
